# docshape

Docshape is a TypeScript semantic document compiler. It validates technical writing as a typed graph before prose is finalized.

Build a SemanticDocumentGraph bottom-up, compile it against a schema, then render Markdown. The MVP does not parse existing Markdown or call an LLM.
